# Archive — 2026-08-13 — pre-v2 documents

On 2026-08-13 the owner amended the project's founding values (evaluative
grading is now in scope, user-data collection is now in scope, the
never-ask-the-owner rule is scrapped, and the project pivots federal-first).
That is a constitutional change: the documents in this directory were written
under the old values and are **superseded, not deleted**. They are preserved
unchanged, with full git history (`git mv`), as the permanent record of what
the project's rules were through INC-0..INC-12.

Nothing still true was lost: `IMPLEMENTATIONv2.md` Appendix B carries a
disposition table with one row for every section and decision of the archived
spec and every item of the archived scope document — each marked carried
forward, amended, or retired, with the reason.
